# Políticas de publicação consultadas

Consulta realizada em 13 de agosto de 2026. As políticas podem mudar; confira
as páginas oficiais novamente antes de publicar uma nova versão.

## ElevenLabs

- [Publicação e licença comercial](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform)
- [Termos de uso](https://elevenlabs.io/terms-of-use)
- [Política de uso proibido](https://elevenlabs.io/use-policy)

Os materiais oficiais informam que saídas produzidas durante um plano pago
podem ter licença comercial, desde que o usuário possua os direitos necessários
e cumpra os termos e a política de uso. Serviços beta podem ter restrições
adicionais. O projeto permanece gratuito por política própria e pelas
diretrizes de conteúdo de fã.

## GitHub

- [Arquivos grandes](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)
- [Releases](https://docs.github.com/en/repositories/releasing-projects-on-github)

O Git normal bloqueia arquivos acima de 100 MiB. O pacote do mod deve ser um
asset de Release e nunca um arquivo commitado no repositório.

## CD PROJEKT RED

- [Fan Content Guidelines](https://www.cdprojektred.com/en/fan-content)

A página do projeto e a Release devem deixar claro que se trata de trabalho de
fã não oficial, gratuito e não endossado pela CD PROJEKT RED.
